# Чек-лист электрики büro42

Интерактивный чек-лист электрики для интерьеров и общественных помещений: уровни оснащения (Минимум / Стандарт / Максимум), развёртки стен по помещениям, умный дом, расчёт нагрузки калькулятор освещённости и эскиз однолинейной схемы щита.

Открыть: https://archburo42.github.io/buro42-electrika/

Отметки и проекты хранятся в браузере посетителя. Приложение — справочный инструмент, не заменяет проект электроснабжения.
